# 麻將牌面圖

- 萬、筒、條、字牌、牌面底 (`Front.svg`)、牌背 (`Back.svg`)：
  來自 [FluffyStuff/riichi-mahjong-tiles](https://github.com/FluffyStuff/riichi-mahjong-tiles) 的 Regular 版本，
  公有領域 (CC0)，見 `LICENSE.md`。
- 花牌 (`Spring` `Summer` `Autumn` `Winter` `Plum` `Orchid` `Chrysanthemum` `Bamboo`)：
  本專案自製，風格比照上述圖組；左上角編號對應門風 (1 東、2 南、3 西、4 北)。
- `HakuFrame.svg`：本專案自製的白板 (台灣常見的藍色方框)。原圖組的 `Haku.svg` 是全白，保留未使用。
- `BackGreen.svg`：由 `Back.svg` 改成綠色並加上內框，遊戲中的牌背都用這張。原本紅色的 `Back.svg` 保留未使用。

每張牌的圖案都是透明背景，使用時疊在 `Front.svg` 上面。
